# 玩家介面與音樂載入流程

基準：`d985d91b99178b0b9b286844e4f16c9f4c147061`。此次只調整選檔驗證、玩家介面及播放生命週期；音樂分析、Worker 演算法、譜面、1.65 秒排程、音樂時鐘公式、碰撞／掃掠、計分及手部控制原始碼皆未修改。

## 玩家流程

- 設定只保留選歌／更換、歌曲名稱、音樂音量、同步偏移、移除音樂，以及原有光劍音效和畫質。移除分析術語、進度及遊戲播放按鈕。
- 音訊副檔名與 MIME 檢查通過後立即關閉設定，在主頁中央顯示「載入中…」。讀檔、解碼、降採樣無整體真實進度時使用不確定量條；收到分析 Worker 的實際進度後使用該進度，不顯示虛構百分比。畫面更新仍由原 RAF 執行，UI 每 150 ms 取樣。
- 攝影機及可信光劍已就緒、設定關閉、頁面可見且 AudioContext 已 running 時，自動使用原 2.5 秒倒數。若音訊受瀏覽器限制，留在待播放，點主頁播放才恢復 AudioContext。稍後才開啟攝影機時不擅自開始歌曲。
- 歌曲可遊玩後，右上依序為播放／暫停、重新開始、攝影機、設定。設定開啟即暫停，關閉不自動續播。暫停保留原時間、譜面、已完成事件與分數。重新開始清空目標／碎片／分數，重用原音訊 Buffer 及同一譜面，不重新解碼分析；暫停、播放中、結束後均可重開。攝影機尚未就緒時先重設為待開始。
- 替換／移除以載入版本及播放請求序號使舊非同步結果失效；快速重按只讓最後一次請求建立歌曲來源。移除歌曲即清空譜面、得分及兩個音樂圖示。停止攝影機或離頁會暫停；離頁載入中也會取消、終止 Worker 並清除中央載入介面。

## 音訊檔案限制

明確支援 MP3、WAV／WAVE、M4A、AAC，並保留瀏覽器可解碼的 FLAC、Ogg／Opus、AIFF。實際編碼支援依裝置。空 MIME 或一般二進位 MIME 只有在副檔名、容器內容及解碼皆通過時才可匯入。明確的圖片／影片 MIME、錯誤副檔名及不相符 MIME 會拒用。

解碼前檢查音訊簽章；M4A 解析 ISO BMFF track handler，拒絕含 `vide` 的容器，必須有 `soun`；Ogg 逐頁檢查起始串流只允許已知音訊編碼，拒絕混入影片。沒有使用影片音訊抽取。最後仍須由真實 `decodeAudioData` 成功且通過原有 64 MB／15 分鐘／解碼記憶體限制。原生選檔器的「所有檔案」或來源選單由 OS 控制，HTML 不保證完全隱藏，但程式會拒絕非音訊。

## 驗證與限制

172 項 Node 測試、TypeScript、正式建置、154 項正式 React／WebGL 檢查與 23 項 UI 檢查通過；測試結果存於 `player-browser-checks.json`。包含真實原創 WAV／MP3 解碼、分析 Worker、音訊播放、碰撞及最終成績；自動倒數、主頁圖示順序、暫停／接續、連按重開、結束後重開、攝影機未就緒等待及移除。UI 測試覆蓋錯誤檔案、不確定載入、離頁取消、錯誤通知、攝影機取消與資源釋放。原音色及控制／姿態／雙拳回歸測試保留。320×568、390×844、844×390、1024×768 瀏覽器視窗確認控制順序、44 px 以上觸控範圍及無按鈕重疊。

手部觀測與攝影機串流使用合成／模擬輸入；WebGL、音樂解碼、Worker 及 AudioContext 為真實瀏覽器。明確的 QA render pump 用於避免背景頁節流，不代表實測裝置 FPS。仍須使用者在 iPad Safari／Android Chrome 驗收原生選檔來源、M4A／AAC 等裝置解碼、使用者手勢音訊限制、實際聲畫同步及觸控操作。沒有宣稱通過平板實機或改善追蹤效能。
