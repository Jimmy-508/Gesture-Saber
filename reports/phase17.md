# Phase 1.7 — Golden Twin Saber

基準：`1d8c440097f9a7ebcb8be813f4bcc0d16dcc88ef`。正式網址：https://jimmy-508.github.io/Gesture-Saber/ 。這一版更換武器互動模式，不更換 MediaPipe 模型、推論頻率、攝影機解析度或偵測門檻。

## 正式接線與主控手

`TrackingSession → App.receive → SaberScene.receiveControls → WeaponControl → 單一 ControlHand → 同一 weapon.group`。原始兩手觀測仍供既有 Phase 1.6 ControlIdentity 做身分連續性與一對一配對，但只有主控手會進入位置／方向估計。第二隻手沒有另一組 PalmPose、MotionFilter、Three.js 握柄或獨立武器聲道。

第一隻有效且可建立身分的手取得主控。首次同幀雙手時，先選手別分數較高者，同分固定選校正後 Left；此規則與模型輸出順序、畫面左右位置無關。沿用 Phase 1.6 原始 Right→內部 Left／藍色的預設映射，實際手別使用既有左手校正確認，沒有未經驗證地反轉模型標籤。主控期間持續沿用相同身分，不以第二隻手的位置或雙手中點控制武器。

短暫零手／主控未配對會停止移動與新光帶生成，保留最後姿態。沿用 180 ms stale／260 ms 收劍／420 ms 隱藏時限；420 ms 清除主控、型態及姿態，之後可由新手取得單刃武器。第二隻手消失不會解除雙頭。

回退設定保留原 PalmPose／MotionFilter，兩種姿態核心共用單武器主控與變形政策。這是刻意的相容範圍：不恢復舊版雙獨立武器／第二套身分政策。切換核心、校正、停止攝影機、切頁都會安全清除武器狀態。

## 握柄與光刃

原握柄實際 Y 邊界約 −0.600000 至 +0.126928，長 0.726928。中間增加 0.363464，總長 1.090392（精確 1.5 倍）。鋼製 Lathe 下端整段平移；中段直握持面、橡膠區及縱向握持條延長。環紋按原尺寸與間距重複增加，按鈕／LED／上端發射器不縮放；下端裝飾只平移。沒有非等比例縮放整把握柄。四種原始金屬、鈦、橡膠及指示材質仍分批合併。

前刃局部 Y=0.12，尾刃位於加長握柄底部約 Y=−0.963464、局部 Z 旋轉 π。兩者都是同一父節點的子節點，+Y／−Y 同軸；不存在第二個位置或方向控制器。光刃原長 2.75、原半徑輪廓、尖端、光暈平面幾何及 Shader 字串保持。兩端共用不可變幾何，各自持有動畫／顏色 uniforms 與重用的 TrailBuffer。

變形時原刃平順轉金並短暫增亮；尾刃以原 0.16 秒伸展／0.12 秒收縮機制呈現。金色核心 `#ffd454`、內暈 `#ffe46a`、外暈 `#ffb627`，沿用原白色高亮核心 Shader；握柄金屬材質及原手色指示燈不變。收回後前刃恢復主控手的原藍／紅。相機、背景、品質策略與光帶視覺演算法未更改。

## 切換命令

`TwinGesture` 完全獨立於位置／方向計算。必須有兩份有效且非重複的觀測、不同且非歧義的配對身分、有限且至少 0.65 的一致原始手別分數，才檢查雙拳。使用四指骨段夾角、指尖與掌部中心的三維相對距離、掌尺度；至少三指有正面彎曲證據。缺失指尖、世界與影像開拳／握拳矛盾均為 UNKNOWN，不以低伸指數猜握拳。

靠攏使用校正影像長寬比後的掌心距離／平均掌尺度，比例 ≤1.7，過度重疊小於最小掌尺度的 0.6 倍拒用，兩手尺度差不能超過 2 倍。尺度由手腕與 MCP 可用幾何取得，不使用像素門檻。模型完全零手、重複候選、雙手交叉歧義、低分或不一致標籤不觸發。

連續 ≥180 ms 且至少三份 JOIN 才切換一次；超過 125 ms 的觀測缺口會重新累積穩定時間。切換後鎖住，持續同姿勢不再觸發。可信鬆拳或分離（距離比例 >2.25）連續 ≥140 ms 才重新啟用。第二隻手在主控持續可見下連續缺席 ≥420 ms 也能重新啟用，但不改變已鎖定型態；單幀缺席／零手／不明觀測不等同解除。重新形成 JOIN 後才再次切換。

## 音訊與資源

Phase 1.1 原始音訊圖、振盪器、頻率、波形、噪聲、濾波、音量與速度映射不變。原有 SaberAudio 仍預備兩個可選手色聲道，但武器只使用主控的那一個；另一聲道不啟動嗡鳴。尾刃變形僅重用同一聲道的原 80→580 Hz／550→45 Hz 瞬態包絡，不新建節點、不增加另一套嗡鳴或總音量。

維持初始化預備、Shader 預熱、資源 SHA-256 驗證、模型／WASM 快取與引擎重用。尾刃使用相同材質系統與共用幾何；沒有後製或新增粒子。每個渲染影格沿用重用的 Vector3／Quaternion／Color／光帶陣列，手勢判定只在推論結果到達時執行。歷史雙劍 QA 頁改用封存的 `benchmarks/phase16-scene.ts`，不接入正式首頁。

## 實機待驗收

需要 iPad Safari／Android Chrome 實際確認：實際左右手先進與校正、雙拳靠攏的辨識成功率／舒適距離、不同拍攝距離與手掌角度、雙手遮擋與交叉時的保守拒用、快速主控跟手性、雙頭伸縮及金色可見度、觸控設定與原音效聽感。模型若沒有提供可信兩手證據，不會猜測切換；合成測試不能保證真實 MediaPipe 在雙拳接近時持續輸出兩隻手。本次沒有真實平板跟手測試，也沒有宣稱實測延遲或 FPS 改善。
